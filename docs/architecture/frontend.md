# Frontend

## Обзор

Фронтенд построен на React + TypeScript и организован по фичам. Каждая фича — изолированная подсистема со своим публичным API. Общие принципы: feature-based структура, минимальная связность, переиспользование через `index.ts`.

## Базовые принципы

- **Фичевая изоляция.** Фичи взаимодействуют только через публичные экспортируемые интерфейсы.
- **Повторяемый шаблон.** Все фичи и подфичи строятся по одной схеме (слои `core`, `runtime`, `components`, `adapters`, `modules`).
- **Переиспользование через shared.** Общие утилиты размещаются в `shared/`, но не смешиваются с кодом фич.
