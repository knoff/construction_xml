# Техническая документация

Этот раздел предназначен для разработчиков, аналитиков и администраторов. Здесь собраны материалы по архитектуре, процессам разработки и тестированию.

## Что внутри

- Подробная схема архитектуры проекта и описания подсистем.
- Регламенты по API, внедрению изменений и работе с инфраструктурой.
- Стратегия тестирования, чек-листы и инструменты для обеспечения качества.

За актуальность раздела отвечает команда разработки. Перед началом работ проверьте, не обновилась ли схема или регламент, и при необходимости предложите изменения через pull request.
