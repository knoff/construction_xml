# Работа с интерфейсом

> "Рыба" для фиксации страницы в структуре документации
> Корректно заполнить позднее

Ниже приведён обзор основных экранов и паттернов интерфейса сервиса Construction XML.

## Главная страница

- Отображает список проектов с быстрыми действиями.

## Просмотр проекта

- Верхняя панель содержит ключевые сведения: название, заказчик, статус, даты.
- Вкладки «Документы», «Согласования» и «История» позволяют переключаться между разделами без перезагрузки страницы.
- В правом ответвлении показаны связанные задачи и предупреждения о рисках.

## Редактор XML

- Подсветка синтаксиса и автодополнение схем.
- Проверка валидности выполняется автоматически при сохранении и через кнопку «Проверить».
- Секция «Подсказки» отображает ошибки валидации и рекомендации по исправлению.

## Управление задачами

- Доска Kanban помогает отслеживать состояние работ.
- Карточки задач можно перетаскивать между колонками «В работе», «На проверке», «Готово».
- В каждой карточке доступны комментарии, вложения и чек-листы.

## Нотификации

- Уведомления о важных событиях отображаются во всплывающих окнах и на панели «Колокол».
- Настройте предпочтительный канал получения уведомлений в профиле пользователя.

## Советы

- Используйте поиск по команде `Ctrl + K`, чтобы быстро перейти к проекту или документу.
- Закрепляйте часто используемые проекты, чтобы они отображались выше списка.
- Если интерфейс работает медленно, очистите кэш браузера или обратитесь к администратору.
